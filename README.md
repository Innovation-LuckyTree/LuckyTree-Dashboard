# LUCKY THREE DASHBOARD (ReactTS + Vite)

This project is for **Lucky Three Dashboard**. This is created using **React TS + Vite**. The design framework is based on **Ant Design**. Please use **custom-hooks** to manage component level state management and **Zustand** for global and shared states. Styles are from Ant design. If Ant components can't support, fallback to **Tailwind** and if it still cannot support, go to classic styles/css

## Steps to run locally:
1. Clone the repository.
2. ***npm install*** in the target project.
3. Run ***npm run dev*** to run the project locally

*Note: check the .env file to for the pointed endpoint*
